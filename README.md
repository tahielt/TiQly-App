## Características Principales

-   **UI/UX Premium**: Diseño inmersivo en modo oscuro con glassmorphism, gradientes suaves y animaciones a 60fps utilizando `react-native-reanimated`.
-   **Flujo de Venta**: Experiencia de compra fluida con generación integrada de códigos QR (`react-native-qrcode-svg`).
-   **Contenido Multimedia**: Fondos de video, previsualización de audio con retroalimentación háptica (haptics) y visualizadores dinámicos.
-   **Mapas Interactivos**: Descubrimiento de venues integrado con marcadores y estilos personalizados.
-   **Núcleo Seguro**: Construido sobre Supabase para una autenticación robusta y gestión de base de datos.
-   **Alto Rendimiento**: Optimizado para iOS y Android utilizando las últimas versiones de Expo SDK.
